M3ALEM-PRO — site vitrine HTML/CSS

Pages : accueil et six pages de services.
Styles : style.css
SEO technique : robots.txt, sitemap.xml, balises canonical, Open Graph et données structurées JSON-LD.
Icône : favicon.svg
URL GitHub Pages : https://samani12.github.io/m3alem-pro-site/

Outils open source intégrés dans GitHub Actions :
- Lighthouse CI (GoogleChrome/lighthouse-ci) : audit de performance, accessibilité, bonnes pratiques et SEO ; rapports enregistrés comme artefacts GitHub.
- Lychee (lycheeverse/lychee-action) : vérification automatique des liens internes.
- Contrôle Python intégré : titres, H1, descriptions, canonical, JSON-LD et cohérence du sitemap.
- Dependabot : vérification hebdomadaire des mises à jour des GitHub Actions.

Les contrôles se lancent sur chaque Pull Request vers main, chaque push vers main, chaque lundi et manuellement depuis l'onglet Actions.
Avant publication, vérifier les URL GitHub Pages, le téléphone, les services, les zones desservies et la propriété Search Console.
