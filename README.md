## Publication GitHub Pages
URL configurée : https://samani12.github.io/m3alem-pro-site/
Le dépôt doit publier depuis la branche `main` et le dossier racine (`/`). Si le domaine ou le chemin Pages change, mettre à jour les URL canonical, Open Graph, JSON-LD, `robots.txt` et `sitemap.xml`.

## À vérifier après publication
1. Ouvrir chaque URL et tester téléphone / WhatsApp.
2. Vérifier le fichier de propriété Google Search Console.
3. Soumettre le sitemap dans Search Console.
4. Confirmer que les quartiers cités sont réellement desservis.
5. Ne pas ajouter d'adresse, horaires, tarifs ou avis structurés sans données réelles.
